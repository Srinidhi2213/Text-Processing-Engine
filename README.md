# Text Processing Engine

A Python-based text processing engine implementing:

- Trie-based Autocomplete
- KMP Pattern Matching
- Levenshtein Spell Correction

## Technologies

- Python
- Trie
- KMP Algorithm
- Dynamic Programming

## Features

### Autocomplete
Provides prefix-based word suggestions.

### Pattern Search
Uses KMP for efficient string matching.

### Spell Correction
Uses Levenshtein Distance for typo correction.

## Run

```bash
python main.py
```
